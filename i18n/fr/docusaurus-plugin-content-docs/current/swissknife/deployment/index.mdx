Choisissez la méthode adaptée à votre environnement.

- [Docker](./docker.mdx) pour installer une image publiée avec le tableau de bord ou le serveur seul.
- [Kubernetes](./kubernetes.mdx) pour déployer le serveur et le tableau de bord avec Helm.
- [Compilation depuis les sources](./source.mdx) pour construire les binaires et les images d’une version donnée.
