SwissKnife utilise [SeaORM](https://www.sea-ql.org/SeaORM/) pour accéder à PostgreSQL ou à SQLite. Les deux moteurs sont testés. SQLite est utilisé par défaut.

Consultez les [paramètres de connexion à la base de données](./index.mdx#database).

## Proposer un autre moteur {#not-finding-your-preferred-database}

Si votre installation nécessite un autre moteur SQL, décrivez votre besoin dans un [ticket SwissKnife](https://github.com/bitcoin-numeraire/swissknife/issues).
