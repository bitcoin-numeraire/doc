## Déployer le logiciel

Choisissez un [mode de déploiement](./deployment/index.mdx). Vous pouvez utiliser une image Docker, installer les charts Helm sur Kubernetes ou compiler le logiciel.

## Configurer l’instance

Le [guide de configuration](/swissknife/configuration/index.mdx) décrit la base de données, la connexion au fournisseur Lightning et l’authentification. Consultez aussi le [fichier de configuration par défaut](/swissknife/configuration/default.mdx).

## Utiliser SwissKnife

Le [guide d’utilisation](/swissknife/usage/index.mdx) présente le tableau de bord. La [documentation d’architecture](/swissknife/architecture/index.mdx) décrit l’intégration du nœud Lightning, du registre et de l’API.

Si vous rencontrez un problème, ouvrez un [ticket sur GitHub](https://github.com/bitcoin-numeraire/swissknife/issues) ou [contactez Numeraire](https://numeraire.tech/fr/contact).
