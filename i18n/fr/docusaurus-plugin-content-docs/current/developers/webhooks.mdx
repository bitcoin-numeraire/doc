:::note Fonctionnalité prévue

La version publiée de SwissKnife ne propose pas encore de webhooks. Pour suivre les changements depuis votre application, interrogez périodiquement l’[API REST](https://api.numeraire.tech/docs).

:::

Un webhook envoie une notification HTTP à votre application lorsqu’un événement se produit. Les événements pris en charge et le format des notifications seront précisés à la publication de cette fonctionnalité.
