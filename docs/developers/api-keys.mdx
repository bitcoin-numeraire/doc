Use an account API key to connect a server-side application to SwissKnife. The key can read and operate the wallets owned by its account, including sending payments. The wallet ID in a request selects the wallet for that call. Additional scopes grant administrative access across accounts.

## Create an account key

1. Sign in to the [Numeraire dashboard’s API Keys page](https://app.numeraire.tech/build/api-keys). In a self-hosted dashboard, open **Build → API Keys**.
2. Under **Personal access tokens**, select **New**. Give the token a name and choose an expiration.
3. Leave administrative scopes empty for this guide. Select **Generate token** and copy the secret while the drawer is open. Store it in your server’s secret store.

## List your wallets

Make the secret available as `SWISSKNIFE_API_KEY` in your shell. Use the hosted API origin below or substitute the URL of your SwissKnife instance.

```bash
SWISSKNIFE_URL=https://api.numeraire.tech

curl --fail-with-body --silent --show-error \
  -H "Api-Key: ${SWISSKNIFE_API_KEY}" \
  "${SWISSKNIFE_URL}/v1/me/wallets"
```

The response is a JSON array. Choose the wallet you want and copy its `id`. An empty array means the account has no wallets yet.

## Read payments for one wallet

Set `WALLET_ID` to the ID you chose, then request its outgoing payment history.

```bash
WALLET_ID=YOUR_WALLET_ID

curl --fail-with-body --silent --show-error \
  -H "Api-Key: ${SWISSKNIFE_API_KEY}" \
  "${SWISSKNIFE_URL}/v1/me/wallets/${WALLET_ID}/payments"
```

A wallet with no outgoing payments returns `[]`. For incoming payments, use the [wallet’s invoices](../swissknife/usage/payments.mdx). See the [REST API reference](https://api.numeraire.tech/docs) for the full response types.

When you retire the integration, open the token’s row menu under **Personal access tokens**, choose **Revoke** and confirm. Other tokens for the account remain usable. The [API key reference](../swissknife/usage/api-keys.mdx) lists administrative scopes and the endpoints for managing keys.
