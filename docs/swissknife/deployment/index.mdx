In order to get started with Numeraire SwissKnife, you will need to install/deploy the software. Choose your preferred method below:

- [Docker](./docker.mdx)
- [Kubernetes](./kubernetes.mdx)
- [Build from source](./source.mdx)

To connect a desktop app to an existing instance, see [Desktop client](./desktop.mdx).


## Umbrel preview

The SwissKnife App Store package is in development. It uses Umbrel’s Lightning Node as its Bitcoin and Lightning provider and keeps SwissKnife accounts and wallet balances in its own SQLite database. The first owner sets a local SwissKnife password.

The default LND certificate on umbrelOS 2.0.1 currently prevents SwissKnife from connecting. Store availability depends on a successful stock installation and a published multi-architecture image. [Umbrel package](https://github.com/bitcoin-numeraire/umbrel-apps/pull/1) · [Certificate compatibility](https://github.com/bitcoin-numeraire/swissknife/issues/545)
