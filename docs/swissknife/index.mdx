Numeraire SwissKnife is a wallet and transaction orchestrator enabling easy integration of Bitcoin, Lightning and Nostr to any entity that wishes so without the complexities of above technologies.

An account can hold several wallets. Each wallet records that account’s balance and payments for one asset on a particular network. The SwissKnife instance maintains the ledger and its configured node settles external payments.

You can run SwissKnife on a desktop, a Raspberry Pi or a cloud server. When you also run the node, you control the installation and its recovery material. In a hosted service, the operator runs the instance and node. An administrator with transaction-write permission can issue invoices and send payments for a selected wallet. To access an account hosted by Numeraire, sign in to the [Numeraire Dashboard](https://app.numeraire.tech).

## Features

- [`Lightning Network`](https://github.com/lnurl/luds). Send and receive payments.
- [`LNURL`](https://github.com/lnurl/luds) support, including [LUD-21 invoice verification](./usage/payments.mdx#lud-21-invoice-verification).
- [`Lightning Address`](https://lightningaddress.com/). Deploy your own Lightning Address infrastructure. Like email, anyone can use identifiers (`username@your.domain`) to send and receive payments.
- On-chain Bitcoin wallet. Address management, wallet sync and transaction preparation before broadcast (for self-hosted Core Lightning and LND).
- Generate invoices.
- Explicit accounts with authentication identities, preferences, and multiple asset-scoped wallets.
- Internal ledger for instant payments on the same SwissKnife instance.
- REST API.
- Frequent contacts.
- `JWKS` with automatic public key retrieval
- Per-account local JWT authentication, activation/reset codes, and password changes.
- `OAuth2` / `OIDC` authentication via OpenID Connect discovery (`auth_provider = "jwt" | "oauth2"`).
- `RBAC`. Fine grained authorization.
- Data availability through pagination and advanced search.
- Advanced [Dashboard](https://github.com/bitcoin-numeraire/swissknife/tree/main/dashboard).
- Runs in the cloud, on your desktop or on a Raspberry Pi (or similar).
- [`Nostr`](https://github.com/nostr-protocol/nips/blob/master/05.md). NIP-05 and Zap support through your Lightning Address.
- Account-owned API keys.
- Provider-derived fee quotes with hard Lightning fee limits.
- Durable account settlement events over SSE with live dashboard updates.

## Liquidity Providers

SwissKnife connects to self-hosted liquidity providers for both Lightning and on-chain Bitcoin. Core Lightning (CLN) and LND are each supported over gRPC and REST (`cln_grpc`, `cln_rest`, `lnd_grpc`, `lnd_rest`):

- [`Core Lightning`](https://corelightning.org/) (via gRPC and REST):
  - Run your own node
  - Manage your own liquidity.
- [`LND`](https://github.com/lightningnetwork/lnd) (via gRPC and REST):
  - Run your own node
  - Manage your own liquidity
